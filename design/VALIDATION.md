# UI 重构本地验证

分支：`ui/dashboard-redesign`。对照基线：`762df1b`。

## 实现范围

- 正式界面变更位于 `go/ui.html`：四个标签页、概览摘要、模板有效期进度条、编辑分区、运行设置、响应式与暗色样式。
- 原有 46 个 DOM 控件 ID 均保留；接口请求、账号与模型归属、探测、存储和后台调度未改动。
- 新增摘要只读取现有状态；范围和代理共用原草稿、差分与确认流程。
- 修正统计起始时间展示，兼容原 `counters.since` 并读取后端已有 `counters_since`。
- 本地预览工具和虚构接口数据仅用于验收，不被嵌入正式插件。
